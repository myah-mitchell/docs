The list above is what the host runs once the fleet has left bootstrap mode. While `docker_stacks_bootstrap: true` is set, the run deploys the host without system-agent and traefik-agent, and with traefik-bootstrap in their place. `nixos-sync.yml` and `komodo-sync.yml` make that swap when they write the host's files, so the list itself never changes. See [Bootstrap mode](../concepts/bootstrap-mode.md).
