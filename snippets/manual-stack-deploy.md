### Deploy the Stacks by hand

The run's last stage has Komodo read the host's Stacks from `komodo/stacks/<host>.toml` in the private repo and deploy them. To create and deploy one in Komodo's UI instead, follow [Deploying a stack by hand](../procedures/deploy-a-stack-by-hand.md).

A Stack made by hand under the name the run would give it is taken over by the next run, not duplicated.
